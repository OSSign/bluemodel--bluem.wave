# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [bluemodel/BlueM.Wave](https://github.com/bluemodel/BlueM.Wave/) project.

## Where are the signed binaries published?
The signed binaries are published by the author on [bluemodel/BlueM.Wave](https://github.com/bluemodel/BlueM.Wave).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/bluemodel--bluem.wave/actions).
